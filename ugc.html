PROCESS
HOW THEY GET MADE

Script to scheduled post

Every reel runs the same five stages. The pipeline is documented, so the output is repeatable instead of lucky.

01 / SCRIPT

Hook first

Written to a timed dialogue window so every line fits its clip. The hook is built before the script: payoff on frame one, motion by one second, open loop by three.

02 / STORYBOARD

Shot by shot

Each beat gets a camera distance, blocking and prop state. No two consecutive shots share a setup — identical framing is the tell that gives AI away.

03 / GENERATE

Locked identity

Image-to-video off a locked character frame, with the prop described verbatim in every prompt so face, wardrobe and object survive the whole cut.

04 / EDIT

Cut tight

Clips trimmed to first and last spoken word, dead air stripped, levels matched, captions burned in. Nothing stays on screen longer than it earns.

05 / DELIVER

Scheduled

Exported 9:16, captioned, queued into the account's posting slots. Three posts a day, per account, without a gap.
